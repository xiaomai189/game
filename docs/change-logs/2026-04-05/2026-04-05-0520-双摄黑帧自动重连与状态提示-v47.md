# Change Log - 2026-04-05 05:20 - 双摄黑帧自动重连与状态提示（v47）

## 改动概述
- `main.py`
  - 增加黑帧检测：基于灰度 `mean/std` 判定单帧黑帧。
  - 增加每路相机状态机字段：`WARMUP / OK / BLACK / RECONNECTING`。
  - 增加黑帧连续计数与按路重连触发（达到阈值后仅重连问题路）。
  - 双路预览顶部与面板状态文字显示 `camera_status`。
  - Web payload 补充 `cameraStatus/cameraStatusReason/blackFrameStreak/reconnectAttempts`。
- `core/camera.py`
  - 新增 `CameraManager.reopen()`，封装 `release + open`。
- `config.py`
  - 新增可配置项：
    - `camera_validation_frames`
    - `camera_black_frame_mean_threshold`
    - `camera_black_frame_std_threshold`
    - `camera_black_streak_frames`
    - `camera_reconnect_cooldown_sec`
    - `camera_warmup_sec`
- `tests/test_camera.py`
  - 新增 `test_camera_reopen_releases_previous_capture`。
- `tests/test_main_runtime_watchdog.py`
  - 新增黑帧检测函数测试（黑帧/亮帧）。

## 变更原因
- 双摄实机中会出现“读帧成功但画面黑屏”的场景，之前缺少运行时自动恢复机制。
- 启动阶段和运行阶段都需要更明确的状态可视化，降低排障成本。
