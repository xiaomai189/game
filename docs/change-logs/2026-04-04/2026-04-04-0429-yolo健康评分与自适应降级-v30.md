# 变更记录：YOLO 健康评分与自适应降级（v30）

## 改动摘要
- 新增识别健康评分（health score, 0~100）。
- 新增运行时自适应控制器：根据健康分自动调节 `infer_scale` 与 `inference_stride`。
- 将健康诊断字段接入 warning、Web payload 与性能报告。

## 代码改动
- [core/utils.py](/E:/AI/yolo-test/game/core/utils.py)
  - `PipelineStats` 新增 `health_score(...)`。
  - `snapshot(...)` 支持附加扩展指标。
  - 新增 `RuntimeQualityController`（低健康降级、高健康恢复）。
- [config.py](/E:/AI/yolo-test/game/config.py)
  - 新增自适应与健康分参数：
    - `adaptive_min_scale`
    - `adaptive_scale_step`
    - `adaptive_max_stride_frames`
    - `adaptive_low_health_threshold`
    - `adaptive_high_health_threshold`
    - `adaptive_adjust_interval_frames`
    - `health_target_render_fps`
    - `health_max_drop_rate`
- [main.py](/E:/AI/yolo-test/game/main.py)
  - 接入 `RuntimeQualityController`。
  - 推理触发从固定 `inference_stride` 改为动态 `runtime_stride`。
  - warning 新增 `health / stride / scale` 实时诊断。
  - Web payload `pipeline` 新增：
    - `healthScore`
    - `inferenceStrideFrames`
    - `inferenceScale`

    - `calibrationProgress`
  - `perf-report` 新增 `healthScoreFinal`。
- [tests/test_utils.py](/E:/AI/yolo-test/game/tests/test_utils.py)
  - 新增健康分逻辑测试。
  - 新增控制器“降级与恢复”行为测试。
