# Change Log - 2026-04-04 07:30 - YOLO 多摄像头独立并行（v39）

## 改动内容
- `config.py`
  - 新增 `camera_sources`、`active_camera_id`、`max_cameras` 配置项。
- `core/camera.py`
  - `CameraConfig` 新增 `source` 字段，支持 index 与 URL 输入。
  - `CameraManager.open()` 按 source 类型选择打开方式并改进错误提示。
- `main.py`
  - 新增参数：
    - `--camera-sources`
    - `--active-camera-id`
  - 新增 camera source 解析函数：
    - `_parse_camera_sources`
    - `_resolve_camera_sources`
  - 主循环重构为多路独立 runtime：
    - 每路独立 `PoseEngine` / `ActionEngine` / `PipelineStats`
    - 每路独立 `persons/roles/health/stride/scale`
  - root payload 保持兼容，并新增：
    - `activeCameraId`
    - `cameras[]`（每路 actions/persons/roles/pipeline）
  - 支持多摄参数在 demo/no-display 下无异常运行。
- `tests/test_main_demo_action.py`
  - 新增 camera source 解析回归测试（混合源、去重、fallback、max 上限）。

## 改动原因
- 将 v38 的单摄双人能力扩展为多摄并行架构，满足后续双机位场景的稳定性需求。
- 采用独立通道策略，避免跨镜头融合带来的复杂性与误判风险。

## 验证结果
- `.\.venv\Scripts\python.exe -m pytest -q`：通过（30 passed）
- `npm run build`：通过
- `npm run preflight`：通过（pytest + web 回归全通过）
- `.\.venv\Scripts\python.exe main.py --demo --max-frames 3 --no-display --disable-websocket --camera-sources "0,1"`：通过

## 兼容性说明
- 旧 root 字段未变，旧前端消费逻辑可继续使用。
- `cameras[]` 为新增扩展字段，不影响历史协议消费方。
