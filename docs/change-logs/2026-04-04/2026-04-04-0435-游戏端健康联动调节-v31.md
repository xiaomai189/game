# 变更记录：游戏端健康联动调节（v31）

## 改动摘要
- 将 YOLO pipeline 指标（`healthScore/stride/scale`）接入 Web 经典模式。
- `classic` 新增健康联动节奏：低健康自动降速并放缓障碍刷新节奏。
- 新增 web 回归测试，验证低健康场景确实触发节奏减速。

## 代码改动
- [web/game/index.js](/E:/AI/yolo-test/game/web/game/index.js)
  - 新增 `lastPipeline` 状态。
  - `sharedState` 透传 pipeline 给 mode。
  - `inject_pose_payload` 支持注入 `options.pipeline`（用于自动化测试）。
  - 诊断栏新增 `health/stride/scale` 显示。
  - `mode.step()` 改为传入 shared state。
- [web/game/modes/classic.js](/E:/AI/yolo-test/game/web/game/modes/classic.js)
  - 新增 runtime 健康字段与 `runtimePaceFactor`。
  - 新增 `computePaceFactor(shared)`，根据 `healthScore` 平滑计算节奏因子。
  - 跑速和刷新间隔应用节奏因子（低健康 -> 降速 + 刷新更缓）。
  - `renderToText` 增加 `runtime` 指标，便于回归断言。
- [scripts/test-web-health-adaptive.mjs](/E:/AI/yolo-test/game/scripts/test-web-health-adaptive.mjs)
  - 新增健康联动回归测试。
- [package.json](/E:/AI/yolo-test/game/package.json)
  - 新增 `test:web-health-adaptive`。
- [scripts/preflight.mjs](/E:/AI/yolo-test/game/scripts/preflight.mjs)
  - 预检新增健康联动回归测试。
