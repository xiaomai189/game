# Change Log: Gameplay Stabilization + Demo Input Modes (v36)

## Summary
- Added resilient input mode system (`auto/camera/keyboard/demo`) for stable gameplay without mandatory camera backend.
- Added transport fallback behavior and reduced demo-blocking dependency on websocket availability.
- Added v36 observability fields and two new regression tests.

## Key updates
- [web/game/index.js](/E:/AI/yolo-test/game/web/game/index.js)
  - Added input mode state machine and APIs:
    - `window.set_input_mode(mode)`
    - `window.get_input_mode()`
  - Added effective-mode logic (`auto` fallback to keyboard when camera offline).
  - Added websocket retry backoff and mode-aware transport lifecycle.
  - Added `demo` autopilot input driver integrated with `requestAnimationFrame` and `advanceTime`.
- [web/index.html](/E:/AI/yolo-test/game/web/index.html)
  - Added `Input` selector (`auto/camera/keyboard/demo`).
  - Added `favicon` data URL to avoid static 404 noise.
- [web/game/modes/classic.js](/E:/AI/yolo-test/game/web/game/modes/classic.js)
  - Upgraded `uiVariant` to `classic-pro-v36`.
  - Added `visual.inputMode` in `render_game_to_text`.
- [scripts/test-web-input-mode-fallback.mjs](/E:/AI/yolo-test/game/scripts/test-web-input-mode-fallback.mjs)
  - New regression for auto fallback and demo mode path.
- [scripts/test-web-round-flow.mjs](/E:/AI/yolo-test/game/scripts/test-web-round-flow.mjs)
  - New regression for round state transitions and diagnostics toggle behavior.
- [package.json](/E:/AI/yolo-test/game/package.json)
