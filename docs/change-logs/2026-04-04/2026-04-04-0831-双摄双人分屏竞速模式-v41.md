# Change Log - 2026-04-04 08:31 - 双摄双人分屏竞速模式（v41）
## 改动内容
- 新增 `dual_race` 模式：
  - 文件：`web/game/modes/dual_race.js`
  - 固定映射：`P1=cam0`、`P2=cam1`
  - 双玩家并行推进，统一 45s 回合计时，结束后按分数判定 `winner`
  - 左右分屏渲染，保留各自独立赛道与动作判定
- 扩展前端模式管理：
  - 文件：`web/game/index.js`
  - 新增 `requestedGameMode/effectiveGameMode`
  - 新增 API：`window.set_game_mode` / `window.get_game_mode`
  - `auto` 模式可根据 `payload.cameras` 自动切换 classic/dual_race
  - `inject_pose_payload` 支持注入完整 `payload`（含 `cameras[]`）用于测试和演示
- UI 控件更新：
  - 文件：`web/index.html`
  - 控制区新增 `Mode` 下拉（Auto/Classic/Dual Race）
- 回归体系扩展：
  - 新增脚本：`scripts/test-web-dual-race.mjs`
  - `package.json` 新增 `test:web-dual-race`
  - `scripts/preflight.mjs` 接入 dual 回归

## 改动原因
- 落地“双摄共同驱动玩法”需求，避免仅主摄驱动导致第二路摄像头无法参与实际游戏。
- 在不破坏 classic 玩法的前提下，提供可切换的双人竞速模式。
