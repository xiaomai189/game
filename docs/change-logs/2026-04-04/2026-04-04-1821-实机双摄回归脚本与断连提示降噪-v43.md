# Change Log - 2026-04-04 18:21 - 实机双摄回归脚本与断连提示降噪（v43）

## 基本信息
- 关联 PRD: `docs/rpd/2026-04-04-1815-实机双摄回归脚本与断连提示降噪-v43.md`
- 变更范围: 实机双摄验证脚本、前端重连降噪、web 回归覆盖

## 改动内容
- 新增 `scripts/verify_live_dual_camera.py`
  - 监听 websocket `frame.cameras[]`，按 `cameraId` 统计有效帧。
  - 支持 `--required-cameras`、`--timeout-sec`、`--min-frames-per-camera`。
  - 达标返回 0，不达标返回非 0。
- 新增 `scripts/test-live-dual-camera.ps1`
  - 调用 `.venv` Python 执行实机双摄验证脚本。
  - 支持自定义 ws 地址、超时与最小帧阈值。
- 更新 `web/game/index.js`
  - 调整 websocket 重连退避：`1.5s` 起步，指数回退，上限 `30s`。
  - 连接条文案新增倒计时与 attempt，降低断连噪声感知。
  - `render_game_to_text()` 增补 `transport` 诊断字段。
- 新增 `scripts/test-web-ws-reconnect-noise.mjs`
  - 验证离线场景下重连节奏受控（`retryCount <= 3`）。
  - 验证连接条文案包含重连状态信息。
  - 验证 `render_game_to_text.transport` 可读。
- 更新 `package.json`、`scripts/preflight.mjs`、`README.md`
  - 纳入 `test:web-ws-reconnect-noise`。
  - 文档补充实机双摄验证命令与 transport 诊断说明。

## 改动原因
- 补齐“实机双摄是否同时被 YOLO 端持续使用”的可执行验收手段。
- 降低 WebSocket 离线时前端重连噪声，提升现场调试可读性。
