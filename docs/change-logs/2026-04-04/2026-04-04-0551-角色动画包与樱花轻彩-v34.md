# Change Log: Avatar Animation Pack + Sakura Visual Preset (v34)

## Summary
- Added an explicit avatar animation state machine for clarity during lane motion, hit, miss, and game-over phases.
- Added runtime visual preset switching (`sakura-lite` / `neon`) while keeping gameplay and YOLO control behavior intact.
- Improved HUD readability and diagnostics output for current avatar skin and visual preset.
