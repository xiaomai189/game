# 变更记录：可玩性验证与后台保活（v22）

## 改动摘要
- 修复 `--no-display` 场景下后端在 `GAME_OVER` 自动退出的问题，改为自动重开局保持服务在线。
- 修复前端切道特效在时间回退情况下可能触发的 `ctx.arc` 负半径错误。
- 重新执行全量回归并完成实机联调，补充可见性证据截图。

## 变更文件
- `main.py`
  - `no-display + GAME_OVER + max_frames==0` 分支由 `break` 改为 `game_engine.start(...)`。
- `web/game.js`
  - 切道特效 `t` 值钳制到 `[0,1]`，并对半径设置最小值，避免 Canvas 渲染异常。

## 变更原因
- 用户反馈“看不到新游戏”；排查发现主要由后端退出导致 websocket 断流。
- 联调时捕获到前端渲染报错，存在稳定性风险，需要同步修复。
