## 改动内容
- `main.py`
  - 新增 `--perf-report` 参数，支持导出运行性能报告 JSON。
  - 引入推理步长控制（`inference_stride_frames`）。
  - 引入自适应推理分辨率（1.0 / `inference_downscale_ratio`）。
  - 引入延迟预算与简化丢旧帧策略（超预算时丢弃一帧并读最新帧）。
  - 增加 `pipeline` 指标统计并透传到 Web payload。
- `config.py`
  - 新增性能配置项：
    - `inference_stride_frames`
    - `drop_stale_frames`
    - `adaptive_resolution_enabled`
    - `latency_budget_ms`
    - `inference_downscale_ratio`
- `core/utils.py`
  - 新增 `PipelineStats`，统计 capture/infer/render FPS、p95 延迟、丢帧率。
- `core/web_payload.py`
  - `build_web_payload` 支持可选 `pipeline` 字段。
- `tests/test_web_payload.py`
  - 增加 `pipeline` 字段断言。
- `tests/test_utils.py`
  - 新增 `PipelineStats` 单测。
- `README.md`
  - 增加 `--perf-report` 参数说明与性能采样示例命令。
