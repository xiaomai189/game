## 改动内容
- 新增 `scripts/run-oneclick.ps1`
  - 支持一键执行：环境检查、依赖安装、Web 构建、后端服务启动、静态服务启动、可选自动打开浏览器。
  - 支持参数：`-SkipInstall`、`-SkipBuild`、`-NoBrowser`、`-Demo`、`-NoDisplay`、`-WebPort`、`-WebsocketPort`。
  - 启动后写入 `logs/oneclick-processes.json`，记录 PID 与端口信息。
- 新增 `scripts/stop-oneclick.ps1`
  - 读取 PID 文件并停止一键脚本拉起的后端/静态服务进程。
- 新增 `scripts/run-oneclick.bat`
  - 提供双击启动入口，内部调用 PowerShell 一键脚本。
- 更新 `README.md`
  - 增加“一键运行（Windows）”章节，包含启动/停止命令与参数示例。

## 改动原因
- 将“环境准备 + 构建 + 启动多进程”合并为单入口，降低演示与部署操作复杂度。
- 提供配套停止脚本，避免手动查 PID 清理进程。
