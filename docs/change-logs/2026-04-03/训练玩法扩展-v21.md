# 变更记录：训练玩法扩展 v21（兼容 classic）

## 基本信息
- 日期：2026-04-03
- 任务/PRD：`docs/rpd/2026-04-03-训练玩法扩展-v21.md`
- 负责人：Codex

## 改动内容
- `web/game.js`
  - 新增训练模式常量与配置：`classic`、`sprint_lane`、`squat_gate`、`reaction_drill`。
  - 默认模式保持 `classic`，确保旧玩法不受影响。
  - 新增训练状态字段：`hp/maxHp`、`intervalPhase/intervalSecLeft`、`combo/maxCombo`、反应模式状态与统计字段。
  - 扩展 `resetRunner / onPose / spawnObstacle / step`，实现三种训练模式的规则与计分。
  - 新增 `squat_gate` 专用障碍渲染与训练 HUD 信息。
  - 扩展 `render_game_to_text` 返回训练字段，增强可观测性。
  - `window.inject_pose_payload` 支持 `squat` 注入，并写入 `state.py` 供逻辑复用。
  - 新增 `window.switch_workout_mode(mode)`，并支持 `0/1/2/3` 热键切换模式。
- `scripts/test-web-workout-modes.mjs`
  - 新增训练模式回归脚本，覆盖模式切换、深蹲门计分/扣血、反应模式目标响应。
- `package.json`
  - 新增脚本：`npm run test:web-workout`。
- `scripts/preflight.mjs`
  - 将 `test:web-workout` 纳入本地一键预检。
- `.github/workflows/ci.yml`
  - 新增 `Web workout regression` 步骤，训练模式纳入 CI 门禁。
- `README.md`
  - 新增 v21 训练模式说明、URL 参数与热键切换说明、新增回归命令。

## 改动原因
- 提升“锻炼身体”导向能力，支持短时高强训练玩法。
- 在新增功能同时，保持旧玩法行为稳定并可回归验证。
