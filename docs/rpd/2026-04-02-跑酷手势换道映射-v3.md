# PRD：跑酷手势换道映射 v3（抬左/抬右/不抬）

## 背景
- 当前跑酷使用身体左右位移切换车道，用户希望改为更明确的手势映射。

## 目标
- 将换道规则改为：
  - 抬左手 -> 左道
  - 抬右手 -> 右道
  - 双手都不抬 -> 中道

## 范围
- In Scope：
  - 修改 `web/game.js` 的换道输入映射逻辑。
  - 更新网页提示文案与 README 操作说明。
  - 执行构建验证并产出 UI 证据图。
- Out of Scope：
  - 不调整 Python 姿态识别模型与关键点算法。
  - 不改动跑酷障碍规则。

## 方案
- 优先读取 `actions.leftHandUp/rightHandUp`：
  - `left=true,right=false` => 左道
  - `left=false,right=true` => 右道
  - `left=false,right=false` => 中道
  - `left=true,right=true` => 保持当前车道（避免冲突）
- 继续保留下蹲触发护盾机制。

## 验收标准
- [ ] 手势映射符合预期。
- [ ] 提示文案与实际规则一致。
- [ ] `npm run build` 成功。
- [ ] UI 证据图已更新到 `docs/evidence/`。

## 风险与缓解
- 风险：部分场景下“手抬起”阈值抖动导致车道跳变。
- 缓解：后续可增加前端输入去抖（N 帧确认）。
