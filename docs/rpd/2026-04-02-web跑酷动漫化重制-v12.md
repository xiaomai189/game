# PRD：Web 跑酷动漫化重制 v12

## 背景
- 当前前端画面以基础几何体为主（圆形/矩形），缺乏游戏感和动漫风格。
- 用户明确希望界面“更加游戏化”，并带有动漫元素。

## 目标
- 在不改变核心玩法（3 道换道、障碍、护盾、计分）的前提下，完成一版明显动漫风格的前端重制。
- 提升视觉层次：背景氛围、角色表现、障碍造型、HUD 信息架构与按钮观感。
- 保持现有体感控制可用与性能稳定。

## 范围
- In Scope：
  - 重构 `web/styles.css` 的整体视觉语言（配色、字体、卡片、按钮、布局）。
  - 重构 `web/game.js` 的 Canvas 绘制风格（背景、玩家、障碍、特效、状态层）。
  - 增加可测试钩子 `window.render_game_to_text` 与 `window.advanceTime(ms)`。
  - 使用 `develop-web-game` 流程做一轮自动化验证（含截图与控制路径）。
  - 执行 `npm run build`。
  - 补充 change-log 与 UI 证据。
- Out of Scope：
  - 不改后端 YOLO 推理链路。
  - 不新增联机、关卡系统或资源加载管线。
  - 暂不使用外部 AI 素材生成（当前环境缺少 `OPENAI_API_KEY`）。

## 方案
- 视觉方向：`Neon Anime Runner`（青蓝+洋红对比、霓虹描边、动感背景）。
- 画面重构：
  - 背景加入分层渐变、城市剪影、速度线与漂浮粒子。
  - 玩家由纯圆形改为“悬浮机体”风格（机身/推进尾焰/护盾环）。
  - 障碍由纯矩形改为“能量门”风格（警戒条纹+辉光安全道）。
  - HUD 增加品牌副标题、状态徽章、信息层次。
- 可测试性：
  - `render_game_to_text` 输出模式、车道、分数、时间、障碍概览等关键状态。
  - `advanceTime(ms)` 支持确定性步进，便于 Playwright 自动回归。

## 验收标准
- [ ] 页面视觉具备明显动漫游戏感（非基础几何演示风）。
- [ ] 核心玩法保持可用（启动/暂停/继续/重开、换道、碰撞判定）。
- [ ] `window.render_game_to_text` 与 `window.advanceTime(ms)` 可用。
- [ ] `npm run build` 通过。
- [ ] UI 证据输出到 `docs/evidence/`。

## 风险与缓解
- 风险：纯前端程序化美术效果不如外部高质量贴图。
- 缓解：先做可运行风格化版本，后续在 `OPENAI_API_KEY` 就绪后用 `imagegen` 批量替换为动漫贴图资产。
