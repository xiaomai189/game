# PRD：YOLO 端稳态识别优化（v29）

## 1. 背景
- 当前体感控制在复杂光照、短时遮挡、身体轻微晃动时，存在误触发与抖动。
- 现有动作判定以单帧阈值为主，缺少校准与状态机防抖。
- 多人或背景干扰场景下，主目标可能发生跳变。

## 2. 目标
- 提升动作识别稳定性，减少左右切换抖动与手势闪断。
- 引入轻量启动校准机制，使阈值更贴合用户体型与站位。
- 优化主目标选择策略，降低人物切换概率。

## 3. 范围
- `core/action_engine.py`：校准、平滑、防抖、移动迟滞。
- `core/pose_engine.py`：主目标粘性选择（面积 + 距离评分）。
- `config.py`、`main.py`：新增参数并接入。
- `tests/test_action_engine.py`、`tests/test_pose_engine.py`：新增回归测试。

## 4. 方案
- 启动校准：
  - 使用肩宽、肩髋躯干长度、躯干中心 x 作为基准。
  - 达到最小样本后进入 calibrated 状态，后续缓慢自适应更新。
- 动作防抖：
  - 对 `left_hand_up/right_hand_up/squat` 使用进入/退出帧门限。
  - 左右移动采用迟滞阈值：`enter > exit`，减少边界来回抖。
- 主目标粘性：
  - 在每帧候选人中按面积与距离综合打分，优先保持上一帧主目标。

## 5. 验收标准
1. 单元测试通过：`pytest -q`。
2. 构建通过：`npm run build`。
3. 动作识别在短时抖动输入下不出现单帧误触发（由新增测试覆盖）。
4. 主目标选择在双候选扰动场景下具备连续性（由新增测试覆盖）。

## 6. 风险与应对
- 风险：参数过严导致动作响应迟缓。
- 应对：所有阈值参数化，默认取保守值；必要时按现场调参。
