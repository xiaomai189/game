# PRD：一键部署运行 v20

## 背景
- 当前项目可以通过多条命令分别完成环境准备、Python 主程序启动、Web 静态服务启动。
- 对演示和交付场景来说，手动执行多步命令成本高，容易漏步骤。

## 目标
- 提供 Windows 本地“一键运行”脚本，完成依赖准备与服务启动闭环。
- 降低首次部署和演示启动门槛，保证失败时有明确错误提示。

## 范围
- In Scope
  - 新增一键启动脚本（PowerShell）：自动创建/复用 `.venv`、安装依赖、执行 Web 构建、启动后端与静态服务。
  - 新增一键停止脚本（PowerShell）：按 PID 结束一键启动拉起的进程。
  - 新增批处理入口（`.bat`）：支持双击触发一键启动。
  - README 增加“一键运行”说明。
- Out of Scope
  - 不改 YOLO 推理逻辑、动作规则、游戏玩法。
  - 不做云端部署与容器化改造。

## 方案
- `scripts/run-oneclick.ps1`
  - 参数化支持端口、是否跳过安装、是否跳过构建、是否自动打开浏览器、是否 demo 模式。
  - 启动成功后写入 `logs/oneclick-processes.json`（记录进程 PID），用于后续停止脚本。
- `scripts/stop-oneclick.ps1`
  - 读取 PID 文件并结束相关进程，完成清理。
- `scripts/run-oneclick.bat`
  - 双击执行 `run-oneclick.ps1`，降低终端门槛。

## 验收标准
- [ ] 执行 `.\scripts\run-oneclick.ps1` 可自动拉起后端与 Web 服务。
- [ ] 浏览器可访问 `http://127.0.0.1:8080`。
- [ ] 执行 `.\scripts\stop-oneclick.ps1` 可停止一键启动的后台进程。
- [ ] `npm run build`、`npm run test:web-gesture`、`pytest -q` 通过。
- [ ] README 中包含一键运行与停止指引。

## 风险与缓解
- 风险：本机未安装 `python`/`node` 导致启动失败。
- 缓解：脚本启动前执行命令检查并给出可操作错误提示。
