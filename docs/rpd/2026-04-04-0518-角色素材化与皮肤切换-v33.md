# PRD：角色素材化与皮肤切换（v33）

## 1. 背景
- v32 已完成“动漫占位角色 + 2.5D 场景”视觉升级，但角色仍以程序绘制为主。
- 需要将角色视觉进一步素材化，支持皮肤切换，并确保素材缺失时不影响可玩性。

## 2. 目标
- 建立角色皮肤 `manifest`，将动作状态与资源路径配置化。
- 支持运行时切换皮肤（至少 2 套可用皮肤 + 1 套回退皮肤）。
- 在素材缺失/加载失败场景自动回退到程序绘制角色。

## 3. 范围
- `classic` 模式角色渲染模块：增加 sprite 加载与回退机制。
- 页面 HUD：新增皮肤切换控件。
- 新增角色皮肤回归测试脚本。

## 4. 方案
- 新增 `avatar manifest`：定义 `idle/run/shift/shield/hit` 对应资源。
- 新增 runtime 皮肤切换 API：`set_avatar_skin(skinId)`。
- 渲染优先级：`sprite` > `procedural fallback`。
- 在 `render_game_to_text().visual` 输出皮肤与渲染路径诊断字段。

## 5. 验收标准
1. 可在界面切换皮肤并实时生效。
2. 有资源皮肤显示为 `sprite` 渲染路径。
3. 无资源皮肤自动回退且仍可正常游玩。
4. `npm run preflight` 与新增皮肤回归测试通过。

## 6. 风险与应对
- 风险：图片加载异步导致首帧闪烁或回退误判。
- 应对：皮肤加载后缓存，并在加载期间使用程序角色兜底，避免黑屏。
