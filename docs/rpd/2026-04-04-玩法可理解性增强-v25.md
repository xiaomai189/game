# PRD：玩法可理解性增强（v25）

## 背景
- 用户反馈“控制能用，但看不懂在玩什么”，判断游戏质量差。
- 当前界面缺少模式目标、得分规则、失败条件的即时说明。

## 目标
- 在不改变核心玩法逻辑的前提下，提高“看懂玩法”的速度。
- 增加可玩性诊断区，帮助区分“识别问题”与“玩法问题”。

## 方案
1. 在 HUD 增加模式说明区：
   - `objective`：当前模式的核心目标
   - `legend`：得分/失败规则
2. 增加实时诊断区：
   - 流连接状态
   - 最近输入延迟（input age）
   - 左手/右手/下蹲动作位
   - payload 来源（ws / inject）
3. 统一修正文案与连接状态提示文本，避免乱码影响理解。

## 验收标准
- 页面可直接读到“当前模式目标 + 规则”。
- 诊断区可实时刷新且与姿态输入一致变化。
- 回归通过：`npm run preflight`。

## 风险
- HUD 信息增多可能占用视觉空间；通过紧凑样式降低干扰。
