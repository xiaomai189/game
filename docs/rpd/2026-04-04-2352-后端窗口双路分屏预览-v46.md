# PRD - 2026-04-04 23:52 - 后端窗口双路分屏预览（v46）

## 背景
- 当前 OpenCV 后端窗口仅显示 `activeCameraId` 单路画面，双摄运行时无法在后端窗同时观察两路输入。
- 用户希望后端调试窗口直接看到双路画面与基础状态，便于定位摄像头与识别问题。

## 目标
- 双摄运行时，后端窗口改为左右分屏，分别显示 cam0/cam1 实时画面。
- 保留单摄时原有显示逻辑不变。

## 范围
- In Scope
  - `main.py` 显示链路增强：双路分屏拼接、每路状态标签（camera/source/health/fps）。
  - 保持 WebSocket 数据结构与游戏逻辑不变。
- Out of Scope
  - 不改 YOLO 推理模型与动作判定规则。
  - 不改网页前端渲染逻辑。

## 验收标准
- [ ] 双摄启动时 OpenCV 后端窗可同时看到两路画面（左右分屏）。
- [ ] 单摄启动时仍是原有单画面显示。
- [ ] `pytest -q` 通过，`npm run build` 通过。

## 风险与缓解
- 风险：双路分屏额外渲染增加 CPU 负担。
- 缓解：分屏仅用于后端窗口显示；不影响 websocket payload 与推理链路。
