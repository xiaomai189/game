# PRD：手势换道去抖 v4

## 背景
- 当前换道规则已改为“抬左/抬右/不抬”，但在实际姿态抖动时，车道可能出现快速来回切换。

## 目标
- 为手势换道增加去抖确认机制，提升可控性和稳定性。

## 范围
- In Scope：
  - `web/game.js` 增加手势换道去抖逻辑（短时确认后再切换）。
  - 更新界面提示文案与 README 操作说明。
  - 重新构建并产出 UI 证据图。
- Out of Scope：
  - 不调整 Python 侧动作判定阈值。
  - 不改动障碍机制与护盾机制。

## 方案
- 新增 `laneDebounceMs`（默认 180ms）。
- 当目标车道变化时，不立即切换，而是要求手势持续稳定到达去抖窗口后再生效。
- 双手同时抬起保持当前车道，不进入切换流程。

## 验收标准
- [ ] 手势短抖动不再导致频繁换道。
- [ ] 连续稳定手势可正常换道。
- [ ] `npm run build` 成功。
- [ ] UI 证据更新到 `docs/evidence/`。

## 风险与缓解
- 风险：去抖窗口过长导致响应迟滞。
- 缓解：参数化窗口时长，后续可按体验继续调优。
