# PRD：Web 跑酷动画优化 v18（角色与障碍）

## 背景
- 当前动漫风界面已成型，但角色冲刺感与障碍反馈仍偏静态。
- 需要在不改玩法规则的前提下，进一步提升演出和体感反馈。

## 目标
- 强化角色与障碍动效，提升换道、护盾、通行/失败的视觉反馈。
- 保持当前性能区间，不因特效导致明显掉帧。

## 范围
- In Scope：
  - `web/game.js`：新增角色残影、喷焰粒子、障碍入场和命中/失败闪光动画。
  - `web/game.js`：新增特效质量档 `high/low`，按帧率自动降级。
  - `web/game.js`：`render_game_to_text` 增加 `visual.fxQuality/trailCount/particleCount`。
  - `README.md`：补充动画质量自适应说明。
  - 运行回归验证并补 change-log / evidence。
- Out of Scope：
  - 不改手势换道语义（30ms/70ms/stale 保持）。
  - 不改 Python 端动作判定与模型推理逻辑。

## 方案
- 角色动效：
  - 速度驱动的悬浮幅度、机体前倾。
  - 切道残影和尾焰粒子。
  - 护盾双层旋转环与呼吸脉冲。
- 障碍动效：
  - 入场时 alpha/scale 渐入。
  - 危险门增加扫描条流动，安全门增强脉冲辉光。
  - 通行/失败增加短时闪光反馈。
- 性能边界：
  - 默认 `fxQuality=high`。
  - 帧率持续低于阈值自动降为 `low`（减少粒子和残影），恢复后自动升回。

## 验收标准
- [ ] 角色切道时有明显残影与尾焰。
- [ ] 障碍入场/通行/失败反馈更明显。
- [ ] `render_game_to_text` 含 `visual` 动画状态字段。
- [ ] `npm run build`、`npm run test:web-gesture`、`pytest -q` 全通过。
- [ ] 动画优化后无明显性能退化（低帧时可自动降档）。

## 风险与缓解
- 风险：特效过多影响帧率与可读性。
- 缓解：提供自动降档与固定上限，优先保证操控和信息清晰。
