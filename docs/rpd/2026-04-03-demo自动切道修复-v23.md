# PRD：Demo 自动切道修复（v23）

## 背景
- 用户反馈网页游戏“会在中间与右边不停自动切换”。
- 现场排查确认当前 one-click 以 `demo=true` 运行，后端 `main.py` 的 `_build_demo_action` 会周期性模拟 `right_hand_up`，前端据此自动换道。

## 目标
- 让 `--demo` 默认行为稳定，不再自动触发切道。
- 保留原“自动演示动作”能力，供需要自动跑动展示时手动开启。
- 不影响真实摄像头模式与既有玩法逻辑。

## 范围
- `main.py`：
  - 新增 demo 自动动作开关参数。
  - 调整 `_build_demo_action` 默认输出为中立动作。
- `tests/`：
  - 增加最小单元测试，覆盖 demo 默认不自动动作。

## 方案
1. CLI 新增 `--demo-auto-actions`（默认关闭）。
2. `_build_demo_action(snapshot, frame_count, auto_actions=False)`：
   - `auto_actions=False`：返回全中立 `ActionState`。
   - `auto_actions=True`：沿用当前自动抬手+左右偏移演示逻辑。
3. 主循环在 demo 分支按 `args.demo_auto_actions` 调用。

## 验收标准
- `--demo` 启动时，前端 lane 不应在无人工输入下自动来回切换。
- `--demo --demo-auto-actions` 启动时，保留旧版自动演示行为。
- `pytest -q` 与 `npm run preflight` 通过。

## 风险与取舍
- 默认禁用自动演示后，demo 模式观感会更“静态”；但符合“可控/不乱动”的直觉。
- 若需要展台自动演示，需显式加 `--demo-auto-actions`。
