# PRD：移除三种训练模式，仅保留 Classic（v26）

## 背景
- 用户明确反馈新增三种模式“太烂、没法玩”，要求直接删除。
- 现阶段目标是保持一个可理解、可运行、可维护的单玩法版本。

## 目标
- 删除 `sprint_lane / squat_gate / reaction_drill` 三个模式。
- Web 前端只保留 `classic` 玩法。
- 保持核心体感控制链路与基础回归稳定。

## 方案
1. 前端入口收敛为 classic-only：
   - `web/game/index.js` 仅加载 classic mode。
   - `window.switch_workout_mode` 保留兼容，但固定映射到 classic。
2. 删除三种模式代码文件：
   - `web/game/modes/sprint_lane.js`
   - `web/game/modes/squat_gate.js`
   - `web/game/modes/reaction_drill.js`
3. 清理构建/测试流水线中与 workout 相关任务：
   - 删除 `npm run test:web-workout` 脚本与对应测试文件。
   - 从 preflight 和 CI 移除 workout 回归步骤。
4. 更新 HUD 提示文案为单玩法规则描述。

## 验收标准
- 页面只呈现 classic 规则，不再出现训练模式说明。
- `render_game_to_text().workoutMode` 固定为 `classic`。
- `npm run preflight` 全通过。
- 一键启动可正常运行并可操控。

## 风险
- 删除后失去训练模式功能；这是按用户明确指令执行。
