# PRD：CI 回归门禁 v16（pytest + build + web gesture）

## 背景
- 目前已具备 `pytest`、`npm run build`、`npm run test:web-gesture` 三类验证能力。
- 但这些验证尚未形成固定门禁流程，后续改动存在回归漏检风险。

## 目标
- 将关键验证流程固化为 CI 工作流。
- 提供本地一键预检命令，保证提交前与 CI 检查一致。

## 范围
- In Scope：
  - 新增 GitHub Actions 工作流，执行：
    - Python 测试：`pytest -q`
    - Web 构建：`npm run build`
    - Web 体感回归：`npm run test:web-gesture`
  - 新增本地预检命令 `npm run preflight` 串行执行同一套检查。
  - 更新 README 使用说明。
  - 执行本地验证并补充 change-log。
- Out of Scope：
  - 不改业务逻辑和玩法参数。
  - 不新增 UI 行为或样式改动。

## 方案
- 新增 `.github/workflows/ci.yml`：
  - 触发：`push` / `pull_request`
  - 环境：Ubuntu + Python 3.11 + Node 20
  - 安装依赖：
    - `pip install -r requirements.txt`
    - `npm ci`
    - `npx playwright install --with-deps chromium`
  - 执行门禁命令：
    - `python -m pytest -q`
    - `npm run build`
    - `npm run test:web-gesture`
- 新增 `npm run preflight`，本地对齐同样检查项。

## 验收标准
- [ ] `npm run preflight` 本地通过。
- [ ] CI 工作流语法正确并可执行。
- [ ] `pytest -q`、`npm run build`、`npm run test:web-gesture` 三项均通过。

## 风险与缓解
- 风险：CI 环境缺少 Playwright 浏览器依赖导致失败。
- 缓解：工作流中显式执行 `npx playwright install --with-deps chromium`。
