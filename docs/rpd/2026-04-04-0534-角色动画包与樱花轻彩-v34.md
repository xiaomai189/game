# PRD: 角色动画包与樱花轻彩视觉优化 (v34)

## 1. 背景
- 当前 v33 已有皮肤切换和 2.5D 场景，但角色动作反馈仍偏弱，玩家很难快速理解“当前动作状态”。
- 用户明确希望优先做视觉表现，并指定方向为“角色动画包 + 日系樱花轻彩 + 60FPS 优先”。

## 2. 目标
- 建立可读性更强的角色动画状态机，覆盖 `idle / move_left / move_right / hit / miss / game_over`。
- 增加动画过渡与反馈特效，减少换道和命中反馈“看不懂”的问题。
- 新增樱花轻彩视觉预设，同时保留当前霓虹风格可切换。
- 不影响 YOLO 控制链路和旧玩法可玩性。

## 3. 范围
- `classic` 模式渲染逻辑：角色状态机、动画过渡、命中/失败视觉反馈。
- 前端 UI：新增视觉预设切换控件，诊断信息展示当前视觉预设。
- 对外 API：新增 `window.set_visual_preset`，保持皮肤 API 兼容。
- 回归测试：新增动画与视觉预设相关的 Playwright 自动化脚本。

## 4. 方案
- 在 `classic` 中加入动画状态与过渡时长管理，按运行状态、换道方向、命中/失败结果切换目标状态。
- Sprite 渲染与 procedural fallback 共存，缺失帧资源时按优先级回退，且输出回退原因。
- 视觉预设抽象为配置对象，统一管理背景、障碍、高亮和 UI 联动色。
- 前端入口层接入视觉预设选择与浏览器侧 API 暴露。

## 5. 验收标准
1. 角色在换道、命中、失败、结算阶段具有可区分动画表现。
2. `prototype` 等缺失资源皮肤仍可正常游玩，且 `render_game_to_text().visual` 给出回退原因。
3. 可在运行时切换视觉预设，且 `render_game_to_text().visual.visualPreset` 正确反映当前值。
4. `npm run build`、新增动画回归脚本、`npm run preflight` 全部通过。

## 6. 风险与应对
- 风险: 增加动画计算后帧率波动。
- 应对: 动画参数采用轻量数学插值，不引入额外渲染库；低质量档自动降低特效密度。
