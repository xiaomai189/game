# PRD: 双摄双人分屏竞速模式（v41）
## 1. 背景
- v39/v40 已完成双摄并行采集与后端回退诊断增强。
- 当前玩法仍以单人 classic 为主，无法把 cam0/cam1 同时用于双人竞速体验。

## 2. 目标
- 新增 `dual_race` 玩法模式，固定映射 `P1=cam0`、`P2=cam1`。
- 同一局时间内双人独立判定与计分，回合结束按分数决胜（支持平局）。
- 前端改为左右分屏展示双人赛道与状态，同时保留 classic 兼容。

## 3. 方案
- 前端新增 `dual_race` 模式模块，内部复用 classic 逻辑实例实现双玩家状态并行。
- websocket 数据继续使用现有 payload，`dual_race` 从 `payload.cameras[]` 消费两路动作与管线健康。
- UI 新增 Mode 下拉与双人 HUD 汇总（P1/P2 分数、领先方、连接状态、胜负提示）。
- 对于断流场景，标记对应玩家 `DISCONNECTED`，不影响另一玩家继续进行。

## 4. 验收标准
1. 在 `set_game_mode("dual_race")` 下，`render_game_to_text()` 输出双玩家结构（含 `players.p1/p2`）。
2. 注入 `cameras[]` 动作输入后，P1/P2 车道与状态可独立变化。
3. 页面渲染为左右分屏，且 classic 模式行为不回归。
4. `npm run build` 与 `npm run preflight` 通过，并补充 UI 证据到 `docs/evidence/`。

## 5. 风险与应对
- 风险：双模式切换可能影响现有回归脚本。
- 应对：默认模式保持 classic；新增 dual 专项脚本并纳入 preflight。
