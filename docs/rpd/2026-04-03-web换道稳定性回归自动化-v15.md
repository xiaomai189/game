# PRD：Web 换道稳定性回归自动化 v15

## 背景
- v13 已上线换道状态机（30ms 回中、70ms 反向锁定、stale 冻结）。
- 当前验证依赖临时命令，缺少可重复执行的仓库内自动化回归脚本。

## 目标
- 提供一条固定命令验证关键换道规则，降低后续改动回归风险。
- 让前端关键路径测试可直接复用到日常开发和交付前检查。

## 范围
- In Scope：
  - 新增 Playwright 回归脚本（自动拉起静态服务并执行状态断言）。
  - 在 `package.json` 增加 `test:web-gesture` 命令。
  - 更新 README 说明执行方法。
  - 执行 `npm run test:web-gesture`、`npm run build`、`pytest -q`。
  - 补充 change-log。
- Out of Scope：
  - 不改换道状态机逻辑参数。
  - 不改 Python 推理与动作判定逻辑。

## 方案
- 通过 Playwright 启动浏览器并执行固定手势序列，断言：
  - 左手即时切左。
  - 锁定窗口内反向手势无效。
  - 锁定结束后反向手势生效。
  - 双手放下后 30ms 回中。
  - stale 输入会冻结换道。
- 失败时返回非零退出码，便于 CI/本地一键判断。

## 验收标准
- [ ] `npm run test:web-gesture` 通过。
- [ ] `npm run build` 通过。
- [ ] `pytest -q` 通过。
- [ ] README 命令说明可用。

## 风险与缓解
- 风险：本地端口占用导致测试失败。
- 缓解：脚本提供启动超时和服务可用性检查，并输出明确错误原因。
