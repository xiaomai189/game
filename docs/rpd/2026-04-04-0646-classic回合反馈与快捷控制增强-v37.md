# PRD: Classic 回合反馈与快捷控制增强（v37）

## 1. 背景
- v36 已完成输入模式体系（auto/camera/keyboard/demo）与可玩性兜底。
- 目前在 `GAME_OVER` 后仅显示通用文案，结束原因与下一步操作不够直观。
- 连续测试与演示时仍依赖按钮点击，键盘闭环不完整，影响操作流畅性。

## 2. 目标
- 明确展示回合结束原因（至少区分碰撞结束）。
- 增强 HUD 反馈：补充健康/节奏可视条与当前操作提示。
- 补齐快捷键闭环：`Enter/Space` 快速开始或续玩，`P` 暂停/继续，`R` 快速重开。
- 保持现有玩法规则与动作判定不变，不影响旧功能运行。

## 3. 范围
- 前端逻辑：`web/game/index.js`（快捷键编排、HUD 反馈输出）。
- 玩法状态：`web/game/modes/classic.js`（结束原因、文本态扩展、结束覆盖层文案）。
- 页面结构样式：`web/index.html`、`web/styles.css`（反馈条与提示区域）。
- 自动化回归：新增一条 web 脚本并纳入 `preflight`。

## 4. 方案
- 在 classic 状态中新增 `lastGameOverReason`，碰撞失败时写入 `collision`，重开时复位。
- `render_game_to_text` 新增 `round.gameOverReason` 与 `round.progressPct` 便于外部验证。
- `getHud()` 返回健康分、节奏、风险等级、回合提示等字段，`index.js` 渲染成 HUD 可读信息。
- 新增快捷键路由：
  - `Enter/Space`: READY 启动、PAUSED 恢复、GAME_OVER 重开
  - `P`: RUNNING/PAUSED 间切换
  - `R`: 非 READY 状态直接重开
- GAME_OVER 覆盖层文案增加结束原因与快捷操作提示。

## 5. 验收标准
1. 发生碰撞结束后，界面与文本状态均可看到结束原因 `collision` 对应提示。
2. `Enter/Space/P/R` 在对应状态下动作正确，且不破坏已有方向与下蹲键控制。
3. 新增回归脚本通过，并纳入 `npm run preflight`。
4. `npm run build` 通过，补齐 change-log 与 evidence（含截图/等效证据）。

## 6. 风险与应对
- 风险：新增快捷键与原有方向键冲突。
- 应对：仅在独立键位处理控制流，保留现有方向键逻辑与优先级；新增自动化覆盖状态切换链路。
