# PRD - 2026-04-05 04:00 - 双摄自检提示与黑帧自动重连（v47）

## 背景
- 目前双摄窗口已支持分屏，但启动后是否“两路都有效画面”仍需人工观察。
- 部分情况下第二路会出现黑帧，当前仅在日志侧可间接判断，缺少自动恢复机制。

## 目标
- 在后端窗口顶部增加开机自检状态提示（每路有效画面状态）。
- 当单路连续黑帧时自动重连该路摄像头，不中断主循环。

## 范围
- In Scope
  - `main.py`：增加运行时自检状态数据、窗口叠加显示、黑帧触发重连流程。
  - `core/camera.py`：补充相机重连能力（release + reopen）。
  - `tests/`：新增/更新最小单测，覆盖黑帧判定与重连流程关键路径。
- Out of Scope
  - 不改网页游戏玩法逻辑。
  - 不改 YOLO 模型与动作判定策略。

## 验收标准
- [ ] 后端窗口可看到 `cam0/cam1` 启动自检状态（OK/WARMUP/BLACK/RECONNECTING）。
- [ ] 黑帧持续达到阈值后会自动重连对应 camera，并有可视状态切换。
- [ ] `pytest -q` 与 `npm run build` 通过。

## 风险与缓解
- 风险：重连频繁导致短时卡顿。
- 缓解：增加重连冷却时间与黑帧连续阈值，避免抖动重连。
