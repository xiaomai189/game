# PRD：训练玩法扩展 v21（HIIT 三件套）

## 背景
- 当前跑酷玩法已具备基础体感交互与演示效果，但训练目标偏单一。
- 需要在保持现有识别链路稳定的前提下，增加更偏“锻炼身体”的短时高强玩法。

## 目标
- 新增 3 个训练玩法：`sprint_lane`、`squat_gate`、`reaction_drill`。
- 统一采用短时高强训练节奏（默认 180 秒会话 + 间歇冲刺/恢复）。
- 在状态输出中暴露训练核心指标（模式、HP、节奏、反应目标、连击等），便于自动化验证。

## 范围
- In Scope
  - `web/game.js`：新增玩法模式状态机、模式切换、模式计分规则、HP 与训练节奏器、反应指令逻辑。
  - `web/game.js`：扩展 `render_game_to_text` 输出字段。
  - `window.inject_pose_payload`：支持 `squat` 注入，保证训练模式可自动化回归。
  - 新增 Web 自动化回归脚本覆盖 3 个模式核心行为。
  - 更新 README 并补 change-log / evidence。
- Out of Scope
  - 不改 Python 端 YOLO 推理、动作判定链路。
  - 不引入多人模式、不做后端接口变更。

## 方案
- 模式层
  - 新增 `workoutMode`：`classic | sprint_lane | squat_gate | reaction_drill`。
  - 默认模式为 `sprint_lane`，支持 URL 参数 `mode` 与键盘 `0/1/2/3` 快速切换。
- 训练结构
  - 训练模式默认会话时长 `180s`；`classic` 保持原逻辑。
  - 间歇节奏固定为 `20s sprint + 10s recover`，驱动分数倍率和难度变化。
- 规则层
  - `sprint_lane`：高频换道躲避；冲刺段加分倍率；连击累计提升分数。
  - `squat_gate`：通过判定窗要求下蹲；连续达标有额外奖励。
  - `reaction_drill`：随机动作指令与时限判定；超时/错误扣血；快速反应加分。
- 可观测性
  - `render_game_to_text` 增加：`mode`、`hp`、`intervalPhase`、`intervalSecLeft`、`combo`、`reactionTarget` 等字段。

## 验收标准
- [ ] 三种新模式可启动、可结束、可计分，且不影响 `classic` 行为。
- [ ] 训练模式为 HP 制（非一次失误即结束），HP 归零后结束。
- [ ] `render_game_to_text` 输出新增训练状态字段，且值随玩法变化。
- [ ] 新增回归脚本通过，原有手势回归仍通过。
- [ ] `npm run build`、`npm run test:web-gesture`、`pytest -q` 全通过。

## 风险与缓解
- 风险：模式分支增多导致状态错乱或回归破坏。
- 缓解：抽离模式逻辑函数、保留 `classic` 路径、增加模式级自动化断言。
