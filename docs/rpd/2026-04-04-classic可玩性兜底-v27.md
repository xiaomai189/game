# PRD：Classic 可玩性兜底（v27）

## 背景
- 用户反馈“第一个游戏也不能玩了”。
- 复现后确认：在 demo/识别不稳定场景下，流输入会持续中立，用户几乎无法稳定控制，体验等同“不可玩”。

## 目标
- 给 Classic 增加可靠的本地键盘兜底控制。
- 避免键盘输入被姿态流瞬间覆盖。
- 保持体感控制链路与现有测试兼容。

## 方案
1. 增加键盘兜底：
   - `←/A`：左道
   - `→/D`：右道
   - `↓/S`：下蹲
2. 增加手动输入优先窗口：
   - 触发键盘输入后短时间忽略 websocket 流输入，避免抖回中道。
3. 更新页面提示文案，明确键盘兜底控制可用。
4. 修复 one-click 停止脚本对缺失 pid 文件的容错。

## 验收标准
- 键盘可稳定换道，且释放后可回中道。
- `npm run preflight` 通过。
- 页面提示明确显示键盘兜底说明。
