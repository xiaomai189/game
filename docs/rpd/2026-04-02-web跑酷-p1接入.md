# PRD：Web 跑酷 P1 接入

## 背景
- 当前项目已有姿态识别与本地窗口游戏逻辑，用户希望接入“网页游戏界面”并复用动作输入。

## 目标
- 新增一个网页跑酷小游戏（P1）作为替代前端界面。
- 通过 WebSocket 将 Python 姿态动作实时推送给网页。
- 保持原有本地窗口模式可用。

## 范围
- In Scope：
  - Python 侧新增 WebSocket 广播桥接。
  - Python 每帧推送动作/状态数据结构。
  - 新增 `web/` 跑酷页面（Canvas 实现）。
  - 增加 `npm run build` 构建脚本输出 `dist/`。
  - 产出网页运行截图证据。
- Out of Scope：
  - 不引入复杂前端框架与后端持久化。
  - 不实现多人联机或账号系统。

## 方案
- Python 内部启动 `ws://127.0.0.1:8765`，推送 JSON 帧事件。
- 网页读取姿态动作：左右移动切通道，下蹲触发护盾。
- 跑酷规则：墙体滚动，命中错误通道失败；正确通道得分。

## 验收标准
- [ ] Python 测试通过。
- [ ] `npm run build` 成功。
- [ ] 网页可连接姿态服务并实时更新 HUD。
- [ ] 存在 `docs/evidence/` 下的网页证据图。

## 风险与缓解
- 风险：端口占用导致 WS 启动失败。
- 缓解：提供启动错误提示，支持通过参数调整端口。
