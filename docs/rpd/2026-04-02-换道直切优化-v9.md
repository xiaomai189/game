# PRD：换道直切优化 v9（避免左右切换被强制中道）

## 背景
- 当前已取消全局防抖，左右换道响应变快。
- 但用户反馈从左到右/右到左时，常出现“先切到中间再到目标道”的体感延迟。

## 目标
- 保持左右换道即时响应。
- 避免左右互切过程中的短暂“无手势帧”导致强制切入中道。

## 范围
- In Scope：
  - 修改 `web/game.js` 的换道判定策略。
  - 执行 `npm run build` 验证。
  - 补充变更记录与证据。
- Out of Scope：
  - 不修改后端姿态识别模型和 WebSocket 协议。
  - 不恢复全局防抖。

## 方案
- 引入“仅中道确认窗口”：
  - 左道/右道指令：立即生效（不等待）。
  - 中道指令（双手都不抬）：需稳定持续约 `120ms` 才生效。
- 结果：
  - 左右互切时不会因为过渡帧先掉到中道。
  - 用户主动“放下双手回中道”仍可达成。

## 验收标准
- [ ] 左右互切时不再明显出现“必须先过中道”的现象。
- [ ] 左/右切换仍保持即时。
- [ ] `npm run build` 通过。

## 风险与缓解
- 风险：回中道动作会比左右切换略慢。
- 缓解：仅 120ms；如现场仍觉得慢，可再下调到 80ms。
