# PRD：回中确认窗口 50ms v10

## 背景
- 当前左右直切已优化，但回中确认窗口为 120ms。
- 用户要求将回中确认窗口进一步降低到 50ms。

## 目标
- 将中道提交延迟从 `120ms` 调整为 `50ms`。
- 保持左右直切即时生效逻辑不变。

## 范围
- In Scope：
  - 修改 `web/game.js` 中 `centerCommitMs` 常量。
  - 执行 `npm run build` 验证。
  - 补变更记录与证据。
- Out of Scope：
  - 不改后端识别逻辑。
  - 不改障碍节奏参数。

## 方案
- `centerCommitMs = 120 -> 50`。

## 验收标准
- [ ] 回中触发更快（约 50ms 窗口）。
- [ ] 左右直切仍保持即时。
- [ ] `npm run build` 通过。

## 风险与缓解
- 风险：回中抖动概率小幅上升。
- 缓解：若现场抖动明显，可回调到 80ms。
