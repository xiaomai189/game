# PRD：换道去防抖 v8（即时切换）

## 背景
- 用户反馈当前换道响应仍偏慢。
- 当前前端存在换道防抖逻辑，虽已缩短，但仍引入额外等待。

## 目标
- 取消换道防抖，手势变化后立即切换左/中/右道。

## 范围
- In Scope：
  - 修改 `web/game.js`：移除换道防抖等待。
  - 执行 `npm run build`。
  - 补充变更记录与证据。
- Out of Scope：
  - 不调整姿态识别后端。
  - 不调整障碍速度与生成节奏参数。

## 方案
- 删除 `laneDebounceMs` 相关等待逻辑。
- `onPose()` 中按手势解析结果直接赋值 `runner.lane`。
- 保留“双手同时抬起 -> 保持当前道”的冲突处理。

## 验收标准
- [ ] 左/中/右道切换无等待，手势变化即生效。
- [ ] `npm run build` 通过。

## 风险与缓解
- 风险：在姿态波动场景下可能出现抖动切道。
- 缓解：当前按用户要求禁用防抖；如后续需要，可改为“可配置开关”。
