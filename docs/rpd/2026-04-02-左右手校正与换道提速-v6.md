# PRD：左右手校正与换道提速 v6

## 背景
- 用户反馈当前识别结果中“左/右手”与实际动作相反。
- 用户反馈网页跑酷左中右切换反应偏慢。

## 目标
- 在镜像摄像头模式下，动作引擎输出与用户体感一致的左右手语义。
- 提升网页换道响应速度，降低手势到换道的体感延迟。

## 范围
- In Scope：
  - 更新 `core/action_engine.py` 与 `main.py` 的动作语义映射。
  - 更新 `web/game.js` 的换道去抖参数。
  - 执行 `npm run build` 与 `pytest` 验证。
  - 记录变更并补充等效证据。
- Out of Scope：
  - 不改 YOLO 模型与关键点推理流程。
  - 不改网页障碍物规则与分数机制。

## 方案
- 动作引擎新增 `swap_left_right` 开关：
  - 开启后将左右手腕/肩/髋/膝关键点在动作判定前对调。
  - 在 `main.py` 中根据 `settings.mirror` 自动启用（镜像显示时启用）。
- 前端将 `laneDebounceMs` 从 `180` 下调到 `60`，提高换道响应。

## 验收标准
- [ ] 抬左手时系统判定为左手，抬右手时判定为右手（镜像模式下）。
- [ ] 网页换道响应明显快于当前版本，且不出现严重抖动。
- [ ] `npm run build` 通过。
- [ ] `.\.venv\Scripts\python.exe -m pytest -q` 通过。

## 风险与缓解
- 风险：去抖时间过短导致个别抖动场景误切道。
- 缓解：保留去抖机制（不移除），仅下调到 60ms；后续可按现场再微调。
