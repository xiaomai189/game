# PRD：交付流程规范化

## 背景
- 当前项目已进入原型开发阶段，但交付流程文档约束不完整，缺少统一的任务前置文档、变更留痕与 UI 证据沉淀机制。

## 目标
- 将“强制交付流程”和“测试与验收”规则纳入项目协作规范。
- 提供可直接复用的 PRD/ChangeLog/Evidence 目录与模板。

## 范围
- In Scope：
  - 校验 `AGENTS.md` 是否包含新规则。
  - 在 `docs/rpd/`、`docs/change-logs/`、`docs/evidence/` 建立目录与模板。
- Out of Scope：
  - 不改动业务代码逻辑。
  - 不引入额外构建或测试框架。

## 方案
- 复用现有 `AGENTS.md` 条款，不重复改写。
- 增补文档目录骨架与模板文件，降低执行成本。

## 验收标准
- [x] `AGENTS.md` 已包含强制交付流程与测试验收条款。
- [x] `docs/rpd/TEMPLATE.md` 已创建。
- [x] `docs/change-logs/TEMPLATE.md` 已创建。
- [x] `docs/evidence/README.md` 已创建。

## 风险与缓解
- 风险：团队未按流程执行，模板流于形式。
- 缓解：后续任务以 PRD + change-log 作为合并前置检查项。
