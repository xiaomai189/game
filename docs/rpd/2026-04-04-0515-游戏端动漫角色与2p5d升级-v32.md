# PRD：游戏端动漫角色与 2.5D 升级（v32）

## 1. 背景
- 当前 `classic` 玩法已稳定，但玩家角色仍是几何体，视觉识别度不足。
- 已有 YOLO 健康联动与辅助节奏，需要更直观的视觉承载。

## 2. 目标
- 将玩家表现升级为“动漫人物占位角色”。
- 将赛道升级为 2.5D 透视场景（近大远小、纵深层次）。
- 保持既有控制、碰撞与玩法规则不变。

## 3. 范围
- `classic` 渲染层升级：背景、赛道、障碍、角色表现。
- 增加视觉回归测试，防止后续回退到旧几何风格。
- 输出截图证据与变更记录。

## 4. 方案
- 角色：程序化动漫占位角色（头发/躯干/四肢/姿态），随换道和输入有动态反馈。
- 场景：引入透视赛道、地面网格、分层背景和纵深障碍投影。
- 联动：保留低健康辅助模式，并通过 HUD 与场景色调体现。

## 5. 验收标准
1. 页面可见动漫角色（非圆形玩家）。
2. 可见 2.5D 透视场景与障碍深度效果。
3. `npm run preflight` 全通过。
4. 新增视觉回归脚本通过。

## 6. 风险与应对
- 风险：视觉重构影响现有可玩性。
- 应对：只改渲染，不改碰撞与输入判定；通过现有回归 + 新视觉回归兜底。
