# PRD - 2026-04-04 22:17 - Auto 模式连接修复（v45）

## 背景
- 用户在 `Input=Auto`、`Mode=Auto`、未开始回合时看到 `Waiting pose stream...`，误判为前端无法连接 YOLO。
- 现有逻辑在 Auto + READY 状态会主动关闭 WS，仅在 RUNNING 时连接，导致显示与用户预期不一致。

## 目标
- Auto 模式下不再因为 READY 状态而断开 WS，确保页面能持续显示 YOLO 实时连接状态。
- 保持已有离线回退与重连机制可用。

## 范围
- In Scope
  - `web/game/index.js`：调整 `maybeEnsureTransport` 的 Auto 模式连接策略。
  - `scripts/stop-oneclick.ps1`：增强清理策略，防止残留进程导致状态混乱。
- Out of Scope
  - 不改游戏玩法与动作映射。
  - 不改 YOLO 推理参数。

## 验收标准
- [ ] `Input=Auto` 且 `Status=READY` 时，若 YOLO 可用则连接条显示 connected。
- [ ] `npm run test:web-input-mode-fallback` 通过。
- [ ] `npm run test:web-ws-reconnect-noise` 通过。

## 风险与缓解
- 风险：Auto 模式在未开始状态也会保持 WS 重连。
- 缓解：保留现有重连节流和离线 fallback 文案，不会造成 UI 卡死。
