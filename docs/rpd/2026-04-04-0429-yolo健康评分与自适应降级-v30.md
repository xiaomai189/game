# PRD：YOLO 健康评分与自适应降级（v30）

## 1. 背景
- 已完成识别稳态优化（校准、防抖、主目标粘性）。
- 但运行中仍可能因设备负载或环境变化导致延迟上升、帧率下降，需要自动调节推理成本。

## 2. 目标
- 引入统一“识别健康度分数”（0~100），综合评估当前运行质量。
- 基于健康分自动调节推理参数（分辨率缩放 + 推理 stride），在性能与识别质量之间动态平衡。

## 3. 范围
- `core/utils.py`：新增健康评分与自适应控制器。
- `config.py`：新增健康分阈值与调节参数。
- `main.py`：接入控制器，实时调整 `infer_scale` 与 `runtime_stride`。
- `tests/test_utils.py`：新增健康分与控制器回归测试。

## 4. 方案
- 健康分输入：
  - 渲染 FPS
  - p95 端到端时延
  - 丢帧率
  - tracking quality
  - calibration progress
- 控制策略：
  - 健康分连续低于低阈值 -> 先降 `infer_scale`，再提高 `inference_stride`
  - 健康分连续高于高阈值 -> 先恢复 `inference_stride`，再恢复 `infer_scale`
- 所有策略参数配置化，支持按设备调优。

## 5. 验收标准
1. `pytest -q` 通过，新增控制器测试稳定。
2. `npm run build` 通过。
3. `main.py` 的 warning 与 Web payload 中可看到 health / stride / scale 诊断字段。

## 6. 风险与应对
- 风险：阈值不合理可能导致调节振荡。
- 应对：使用高低双阈值 + 连续帧计数门槛（hysteresis）抑制振荡。
