# PRD: 双人竞速同图与回合规则收敛（v42）
## 1. 背景
- v41 已提供 dual_race 左右分屏与双摄接入，但仍存在三个核心缺口：
  - 双人并非同图（障碍图谱不一致）。
  - 一侧提前 GAME_OVER 会导致体验不统一。
  - 一键启动默认未显式使用双摄源，易出现模式误判。

## 2. 目标
- dual_race 实现“同图竞速”：P1/P2 使用同一套障碍序列和同一回合时钟。
- 回合规则统一：时间到统一结算，单侧失误仅淘汰该玩家，不中断全局回合。
- 一键启动默认双摄（`0,1`），降低联调门槛。

## 3. 方案
- 重构 `dual_race` 模式为“共享赛道状态 + 双玩家独立动作判定”：
  - 共享障碍 `obstacles[]`（safe lane 一致、移动一致）。
  - 共享 `roundEndAt`，统一结束判胜。
  - 玩家状态独立：`alive/connected/lane/score`。
- `render_game_to_text()` 补充双人状态可观测字段（含 `alive` 与共享赛道摘要）。
- 更新 `run-oneclick.ps1` 默认带 `--camera-sources "0,1"`。
- 更新 README 的双摄 dual_race 运行说明。

## 4. 验收标准
1. dual_race 下 P1/P2 在同一时刻看到同一障碍安全道（同图）。
2. 任一玩家碰撞后标记淘汰，但另一玩家继续至计时结束。
3. 计时结束统一输出 `winner`（`p1/p2/draw`）。
4. `scripts/test-web-dual-race.mjs` 覆盖同图与淘汰不终局场景并通过。
5. `npm run build` 与 `npm run preflight` 通过。
