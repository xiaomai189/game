# PRD：跑酷交互方向优化 v2（障碍改为上到下）

## 背景
- 现版本跑酷采用右向左滚动障碍，用户反馈不够直观。
- 体感交互中“左右移动躲避从上方下落障碍”更符合自然认知。

## 目标
- 将网页跑酷障碍运动方向改为“从上到下”。
- 保持现有动作映射（左右移动切通道、下蹲护盾）不变。
- 保证可玩性与可视化反馈不退化。

## 范围
- In Scope：
  - 修改 `web/game.js` 的障碍生成、移动与碰撞判定逻辑。
  - 更新页面提示文案为纵向躲避描述。
  - 重新生成运行证据图。
- Out of Scope：
  - 不改 Python 姿态识别链路。
  - 不新增玩法机制。

## 方案
- 障碍对象从 `x` 轴位移改为 `y` 轴下落。
- 每次生成一排障碍，保留一个安全通道（黄色框）。
- 当障碍下落到玩家高度时进行通道判定，命中安全通道得分，否则失败；下蹲护盾可豁免一次。

## 验收标准
- [ ] 障碍明显从上到下运动。
- [ ] 左右切道可稳定躲避。
- [ ] 失败/得分逻辑正确。
- [ ] 文案和证据图更新完成。

## 风险与缓解
- 风险：障碍速度与出生频率不匹配导致过难/过易。
- 缓解：保留速度与刷新参数，按体验微调。
