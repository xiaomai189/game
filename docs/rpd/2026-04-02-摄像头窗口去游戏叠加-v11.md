# PRD：摄像头窗口去游戏叠加 v11

## 背景
- 用户反馈 OpenCV 摄像头窗口中的游戏内容（目标圈、分数、Game Over 文案）不需要展示。
- 当前该窗口用于姿态观察时，游戏叠加会干扰画面。

## 目标
- 摄像头窗口默认不显示游戏叠加内容，仅保留视频与姿态骨架/关键点。
- 提供可选开关，必要时可恢复显示游戏叠加。

## 范围
- In Scope：
  - 修改 `core/renderer.py` 增加游戏叠加开关。
  - 修改 `config.py` 增加默认配置项。
  - 修改 `main.py` 增加 CLI 参数并传递给渲染器。
  - 修改 `README.md` 说明默认行为与开关。
  - 执行 `npm run build` 与 `pytest` 验证。
- Out of Scope：
  - 不修改 Web 跑酷页面本身。
  - 不修改 YOLO 推理与动作识别逻辑。

## 方案
- 渲染器新增参数 `show_game_overlay`。
- 当 `show_game_overlay=False` 时，不绘制：
  - 目标圈（target）
  - 命中反馈（HIT）
  - 游戏 HUD 文案（Status/Score/Game Over 等）
- 配置默认值设为 `False`。
- 新增参数 `--show-camera-game-overlay`，用于临时开启。

## 验收标准
- [ ] 默认启动时，摄像头窗口无游戏叠加内容。
- [ ] 使用 `--show-camera-game-overlay` 时，可恢复原游戏叠加。
- [ ] `npm run build` 通过。
- [ ] `.\.venv\Scripts\python.exe -m pytest -q` 通过。

## 风险与缓解
- 风险：部分调试场景仍需要游戏 HUD 信息。
- 缓解：保留 CLI 开关按需开启。
