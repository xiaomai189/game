# PRD：稳定性与可运行性优化 v1

## 背景
- 当前原型已具备最小骨架，但在依赖缺失、设备不可用、无人值守验证等场景下的可诊断性与可操作性不足。
- 现有测试覆盖以动作规则为主，缺少对游戏状态与降级路径的验证。

## 目标
- 提升启动失败场景的可读错误信息与退出行为一致性。
- 提供可复用的本地一键初始化脚本，降低环境搭建成本。
- 补充基础单元测试，覆盖游戏命中逻辑与姿态引擎降级行为。

## 范围
- In Scope：
  - `main.py`：增强参数与错误处理（依赖缺失、摄像头失败、可选帧数上限）。
  - 新增 `scripts/bootstrap.ps1`：虚拟环境创建、依赖安装、基础校验。
  - 新增测试：`tests/test_game_engine.py`、`tests/test_pose_engine.py`。
  - 更新 `README.md`：补充脚本和运行方式。
- Out of Scope：
  - 不引入新玩法与 UI 视觉改版。
  - 不进行多人识别或模型训练改造。

## 方案
- 将 `cv2` 改为在 `main()` 内延迟导入，避免环境未装依赖时直接崩溃并给出明确提示。
- `main.py` 新增 `--max-frames`，用于无人值守烟雾验证（跑固定帧数自动退出）。
- 摄像头打开失败时返回非零退出码并打印原因，便于自动化脚本识别失败。
- 增加 PowerShell 启动脚本统一初始化流程。

## 验收标准
- [ ] `python -m compileall .` 通过。
- [ ] 单元测试通过（至少动作引擎 + 游戏引擎 + 姿态引擎降级路径）。
- [ ] `python main.py --help` 可正常输出。
- [ ] 无模型或无 `ultralytics` 时程序可降级运行并给出提示。

## 风险与缓解
- 风险：本机未安装 OpenCV / Pytest 导致无法直接执行完整验证。
- 缓解：提供 bootstrap 脚本；在变更记录中明确未执行项与原因。
