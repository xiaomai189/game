PRD：Windows 本机 YOLO Pose 体感游戏原型
1. 项目名称

Windows 本机 YOLO Pose 体感游戏原型

2. 项目背景

基于普通电脑摄像头与 YOLO Pose 姿态识别能力，在 Windows 本机上实现一套可实时运行的体感游戏原型系统。
系统无需 Kinect、深度相机或专用体感硬件，仅依赖普通 USB 摄像头和一台 Windows PC，即可完成人体关键点识别、动作判定与游戏交互。

该原型用于验证以下方向：

普通 RGB 摄像头是否足以支撑基础体感交互
YOLO Pose 在本机 Windows 环境下的实时性是否满足 demo 演示需求
基于人体关键点规则，是否可以快速构建简单可玩的体感小游戏
后续是否具备扩展为工业交互演示、展厅互动、康复训练、教育游戏等场景的潜力
3. 项目目标
3.1 总体目标

在 Windows 本机上，完成一个可稳定运行的单人体感游戏原型，实现：

摄像头实时采集
人体姿态识别
动作判定
游戏交互反馈
本地界面展示
基础可配置能力
3.2 阶段目标
第一阶段：技术可行性验证

实现摄像头读取、YOLO Pose 推理、骨架绘制、动作识别。

第二阶段：体感游戏原型

实现一个可玩的小游戏，如：

举手击中目标
左右移动躲障碍
下蹲躲避横杆
第三阶段：演示优化

优化帧率、提示文案、交互反馈、UI 呈现，使其具备对外演示能力。

13. 风险与限制
13.1 技术风险
普通 RGB 摄像头容易受光照影响
遮挡时关键点识别可能不稳定
CPU 模式下帧率可能不足
用户距离摄像头过近/过远会影响判定
动作阈值需要现场调试
13.2 产品限制
首版不追求复杂动作识别
首版不支持多人协同
首版不保证所有身高体型都完全一致效果
首版更偏“演示原型”，不是正式商业产品

15. 建议的首版边界

为了避免首版过重，建议你把这次原型 明确限定为：

Windows 本机 + 单人 + 摄像头 + YOLO Pose + 一个小游戏玩法 + 可演示

也就是先把这几个目标做实：

能跑

能互动
能演示
