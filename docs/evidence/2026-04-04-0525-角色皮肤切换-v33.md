# 证据：角色皮肤切换（v33）

## 场景
- 启动 classic 模式后，通过 `window.set_avatar_skin` 切换皮肤：
  - `sakura`（有素材）
  - `prototype`（无素材，触发回退）

## 观察点
- `sakura` 时角色以 sprite 渲染，场景保持 2.5D 风格。
- `prototype` 时角色自动回退 procedural，但游戏不中断。
- HUD 与诊断区可看到当前皮肤标签。
