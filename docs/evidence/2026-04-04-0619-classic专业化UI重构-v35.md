# Evidence: Classic Pro UI Refactor (v35)

## Manual validation flow
- Open `web` build in browser.
- Start/restart round with classic mode.
- Switch avatar and visual preset.
- Toggle diagnostics panel via `Show/Hide Diagnostics`.

## Observed results
- HUD is now structured into clear sections: primary status, controls, diagnostics.
- Diagnostics can be collapsed/expanded without affecting gameplay flow.
- `render_game_to_text().visual.uiVariant` returns `classic-pro-v35`.
- Existing gameplay rules remain unchanged (timer loop + collision game-over).
