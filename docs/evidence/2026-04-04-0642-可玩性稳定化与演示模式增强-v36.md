# Evidence: Gameplay Stabilization + Input Mode Fallback (v36)

## Manual validation flow
- Launch web build without YOLO websocket service.
- Keep `Input=Auto` and verify fallback behavior.
- Switch to `Input=Demo`, start round, step forward and verify autopilot updates.

## Observed results
- `Auto` mode reports keyboard fallback when camera stream is unavailable.
- `Demo` mode can run the classic loop without external pose stream.
- `render_game_to_text().visual` exposes:
  - `uiVariant = classic-pro-v36`
  - `inputMode = demo/keyboard/camera` (effective mode)
